# Geo Distance

An Angular and Python application for calculating the straight-line distance between two cities or countries and viewing them on a map.

## Component documentation

- [Frontend setup and usage](frontend/README.md)
- [Backend setup and API](backend/README.md)

Start the backend first, then the frontend. The frontend runs at `http://localhost:4200` and connects to the API at `http://localhost:8000` by default.
